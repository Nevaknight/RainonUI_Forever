# RainonUI Forever — Changelog

## 0.4.2

- Added a Professions tab, enabled from General settings. It lists Mooncloth and Arcanite Bar cooldowns across characters, with the nearest cooldowns first and reminders that show which character can craft the item.
- Added a crafting batch timer. Its movable box starts above the top-right corner of the profession window and returns there when the window reopens.
- Pix Xizzix's weekly quest reminders in Stranglethorn Vale now start at level 60.
