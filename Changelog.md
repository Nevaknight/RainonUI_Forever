# RainonUI Forever — Changelog

## 0.3.0

- Right-click an item in the all-dungeon loot catalog to add or remove it from favorites.
- The Favorites filter shows starred items regardless of the gear ranking slider.
- The all-dungeon loot setting tooltip now credits wowtbc.gg.
- Added an opt-in vendor confirmation for items that bind when equipped.
- Added the /rainon command to open RainonUI settings.
